# Operating Systems Lab

Lab assignments for the Operating Systems course at IIT Jodhpur.
Mostly Linux shell scripts and Python simulations, run on Ubuntu 24.04 (WSL).

## Contents

| Folder | What it covers |
|--------|----------------|
| `week11-linux-cli/` | Shell pipeline: `find`, `cut`, `paste`, `bc`, and `>>` redirection to build a summary report |

## Running the scripts

    cd week11-linux-cli
    bash copy.sh

Requires a Linux/WSL environment with `bash` and `bc`.

## Notes

Each folder is self-contained, with its own script and a short explanation of what it does.
